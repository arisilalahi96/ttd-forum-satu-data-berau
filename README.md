# e-TTD Berita Acara — Forum Satu Data Kabupaten Berau 2026

Aplikasi penandatanganan kolaboratif **real-time** untuk **Berita Acara Hasil Kesepakatan Forum Satu Data Kabupaten Berau Tahun 2026** (Rabu, 25 November 2026 — Ruang Rapat RKPD Bapperida Kabupaten Berau).

## Akses Default
- **Kode Akses Peserta**: `SDI2026`
- **PIN Panitia**: `202600`

## Fitur Utama
- **Kolaborasi Real-time (WebSocket)**: Seluruh peserta melihat tanda tangan yang masuk secara langsung.
- **Tanda Tangan Langsung & Unggah Gambar TTD**: Goresan pena diperhalus otomatis (*Auto-Beautify Ink Ribbon*) dan unggahan foto tanda tangan dibersihkan latar kertas putihnya secara otomatis.
- **Tampilan Daftar (A–Z) & Naskah Berita Acara (A4)**: Filter berdasarkan kelompok instansi dan status tanda tangan, serta pratinjau langsung lembaran Berita Acara A4.
- **Edit Naskah Langsung di Kertas (Khusus Panitia)**: Panitia dapat mengklik dan mengedit teks Berita Acara langsung di atas tampilan kertas A4 seperti di Word.
- **Unduh Berita Acara Lengkap (`.docx` & `.pdf`)**: Menghasilkan file Word (`.docx` Calibri A4) dan PDF (`.pdf` A4) resmi lengkap dengan seluruh tanda tangan yang sudah masuk.
